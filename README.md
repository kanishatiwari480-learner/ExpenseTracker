# ExpenseTracker

A realistic responsive personal expense tracker built with React + Vite and ready for Vercel.

## Features
- Dashboard with total, monthly, daily and transaction statistics
- Six-month spending trend
- Category spending breakdown
- Add, edit and delete expenses
- Search, category and month filters
- Category management
- INR currency formatting
- Responsive mobile layout
- LocalStorage persistence; no database setup required

## Run locally
npm install
npm run dev

## Deploy
Import this GitHub repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`. No environment variables are required.

Data is intentionally stored in each user's browser, so it persists on that browser/device and is not shared between users.
